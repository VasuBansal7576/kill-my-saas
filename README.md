# Kill My SaaS

An open-source, production-grade conference-program operating system covering the complete lifecycle from call for speakers to a published agenda.

## Status

Product research and architecture are complete. Application implementation has not started yet.

The planned V1 connects:

`event setup → CFP → submissions → reviews → decisions → speaker onboarding → content collection → scheduling → public program`

The product will use real persisted behavior and real integrations—no demo-only workflows, fake success states, or in-memory substitutes for required capabilities.
